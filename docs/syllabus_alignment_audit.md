# Syllabus-alignment audit

The presentation model is limited to weekly seasonal naive, seasonal regression with
Fourier terms, ARMA errors as a tested but rejected extension, pre-scheduled match flags
as an exploratory extension, and ARCH diagnostics.

All earlier experimental model files and reports outside this scope were removed. The
active documentation, configuration, scripts, tests and figures now describe only this
syllabus-aligned analysis. The final selection is based on validation performance and
the student's ability to explain and defend the method.
